# 功能状态与限制

本页是功能完成度的唯一维护位置。这里的“可用”指代码和界面已连接；“待验证”指尚未完成目标平台或真实服务的发行验收。页面已经绘制、核心逻辑已经实现，都不能单独视为完整功能可用。此表描述仓库当前开发预览，不代表已有公开发行包。

| 功能 | 界面与实现 | 限制或待验证内容 |
| --- | --- | --- |
| Harness 版本目录与实例安装 | 可用：npm 版本目录、精确版本安装、运行时校验、实例隔离与启动/停止已接入 | 真实 Harness 组合与目标平台仍需发行前验证 |
| 插件搜索与兼容性 | 可用：搜索结果按当前实例的依赖证据筛选 | 候选目录与上游元数据可能变化；部分版本没有可用的兼容证据 |
| 插件安装与卸载 | 可用：界面回调连接到安装/卸载事务、构建脚本确认和失败恢复 | 首批插件与不同 Harness 版本的端到端矩阵仍待验证；操作进度和失败提示尚不完整 |
| 运行日志 | 可用：进程输出按行显示，按级别着色和筛选 | 不保存到文件，也不提供导出；“始终置顶”按钮仅改变页面状态，不控制系统窗口 |
| 实例详情 | 页面和实例基本信息已接入 | 详情中的部分设置、组件更换和插件管理内容仍为演示或占位；实际插件操作在插件市场 |
| 设置与外观 | 页面已绘制，部分控件仅更新界面内状态 | 设置未持久化；主题、背景等选择尚未作用于应用 |
| 图形资源 | 原创品牌图和背景已入库 | 部分单色与实例图标仍为原创占位图 |
| 打包与公开发行 | 仓库含 Windows/Linux 打包脚本和 CI | 无公开发行版；发行检查与真实服务的端到端测试尚未完成 |

更新功能时，先核对 `crates/core`、`crates/app` 和 `crates/ui` 的连接与验证结果，再修改本表。其他文档可以描述契约和使用方式，但涉及完成度时只引用本页。
