# 排查问题

## 无法下载或校验

确认能访问 `nodejs.org` 与 `registry.npmjs.org`。SHA256 不匹配时不要使用该下载文件，重试安装。错误摘要显示在窗口底部状态栏。

## 实例无法启动

查看“运行日志”；核对工作目录是否仍存在、端口是否空闲，以及所选 Harness 版本是否支持 `web` profile。每个实例的安装和 home 位于数据目录下独立的 UUID 文件夹。

若 `0.1.5-rc.2` 在 Windows 报 HMR 服务缺失或 `registerConfig` 错误，请阅读[上游版本公告](announcements.md)。启动器不会修改该上游版本的依赖或 profile 来掩盖问题。

## 插件没有显示

插件版本必须有匹配的 `@deepseek-ai/*` 依赖范围或项目维护的精确兼容记录。缺少包元数据、声明冲突、GitHub 来源不符时不会提供安装。

## 安装提示构建脚本

阅读对话框列出的 npm 包版本和命令。拒绝会终止本次安装；允许只对该实例中的该包版本生效。若脚本内容无法从 npm 元数据核验，HDSL 会自动拒绝。不要为解决安装失败而批量批准所有脚本。

## 模型与密钥设置

HDSL 不提供 API Key、端点或模型路由的编辑入口。请启动实例后，在 Harness 网页中配置；启动器只在展示日志时对已知密钥做脱敏。
