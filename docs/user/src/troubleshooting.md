# 排查问题

## 无法下载或校验

确认能访问 `nodejs.org` 与 `registry.npmjs.org`。SHA256 不匹配时不要使用该下载文件，重试安装。错误摘要显示在窗口底部状态栏。

## 实例无法启动

查看“运行日志”；核对工作目录是否仍存在、端口是否空闲，以及所选 Harness 版本是否支持 `web` profile。每个实例的安装和 home 位于数据目录下独立的 UUID 文件夹。

## 插件没有显示

插件版本必须有匹配的 `@deepseek-ai/*` 依赖范围或项目维护的精确兼容记录。缺少包元数据、声明冲突、GitHub 来源不符时不会提供安装。

## API Key 无法使用

确认选中了正确实例，且该实例中显示“API Key 已配置”。如需排查其他提供商或未知配置格式，请使用 Harness 原生设置。
