# API 设置

先选择实例，再打开“API 与设置”。当前页面支持 DeepSeek 官方 API：

- 输入新的 API Key 并保存。留空不会修改旧密钥；界面只显示是否已配置。
- 可选填 API Base URL 和新会话默认模型。留空不会覆盖原值。端点仅接受不含用户名、密码、查询参数或 `#` 片段的 HTTP(S) URL；填写无效地址时不会更改密钥或其他设置。
- 要删除当前实例保存的 DeepSeek API Key，点击“移除密钥”。这不会删除其他设置，也不会影响别的实例。
- 其他提供商、未知字段及第三方认证，请在启动实例后的 Harness 原生网页或相应插件中设置。

设置只作用于当前实例。不要把数据目录中的 `.credentials.yaml` 提交到 Git 或发给其他人。
