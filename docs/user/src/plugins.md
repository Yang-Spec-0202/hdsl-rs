# 插件市场

先选择并安装实例。插件市场用 DSH Marketplace 目录发现候选，并核验 npm 包、GitHub 来源、`dsh.bundle` 和当前实例的 Harness 包版本。只有存在明确兼容证据的版本才显示“安装”。

点击“搜索”可按关键词查找；搜索框为空时显示项目人工关注的几个仓库。目录收录或 GitHub 星标不代表一定兼容。若列表为空，说明当前没有满足严格准入条件的安装版本。

安装会停止当前实例，在其 `web` profile 中调用该实例版本的官方 `dsh plugin` 命令，并在安装后检查配置。安装前的 profile 被保存为备份；失败时会恢复原目录。

若 pnpm 拦截构建脚本，HDSL 会逐个显示包名、精确版本及脚本命令。每项都需由您决定；拒绝任一项会中止安装并恢复备份。批准仅保存在当前实例的 profile 中，不会自动用于其他实例。

“当前实例已安装”区列出 `web` profile 中的包。点击某一项的“卸载”，确认后 HDSL 会先停止实例，再用该实例的 `dsh plugin remove` 卸载并检查配置。若检查失败，安装前的 profile 会恢复。切换实例时列表随之更新。
