# 实例与版本

1. 打开“安装新版本”，输入实例名称、Harness 精确版本、已有的绝对工作目录和空闲端口。
2. 点击“创建并安装”，等待状态栏显示完成。页面“获取最新”会读取 npm 的最新版本号。
3. 在“实例管理”选择实例，或在首页点击“启动”。启动后 HDSL 会打开该实例的 Harness Web 页面；“运行日志”显示进程输出。
4. 点击“停止”结束该实例。关闭启动器也会停止由它启动的实例。

“复制版本”预填工作目录和新名称，供您选择另一个版本创建新实例。它不会复制旧实例的 home 或插件。旧实例保持可用。

删除实例会删除其 Harness 安装、插件和专属 home；工作目录本身不会被删除。删除前会出现确认框。端口必须由用户选择空闲值；若已占用，请停止占用端口的程序或新建使用其他端口的实例。
